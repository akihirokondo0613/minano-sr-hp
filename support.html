Support Process

社労士に頼めること。会社の段階と業種から選ぶ

創業直後なら新規適用と雇用保険の設置届、10名を超えたら就業規則と勤怠、50名を超えたら賃金規程と管理職研修。会社の段階によって先に整えるものが違い、業種によって詰まる場所も違います。このページは、自社がどこにいるかを見て、該当する業種の進め方か、該当するサービスの料金へ進むための入口です。

PHASE 01 — 創業期 仕組みをつくる 従業員 10名程度まで

こんな課題が多い

  • 社会保険・雇用保険の加入手続きが未整備
  • 雇用契約書・就業規則がない、または古い
  • 給与計算を経営者自身で資料入力している
  • 助成金を使いたいが、どの制度が対象か分からない

提案できること

  • 社保・労保の加入手続き代行 → 新規適用 60,000円／事業所（労務手続き一覧と期限）
  • 雇用契約書・就業規則のゼロから作成 → 就業規則 180,000円（就業規則の作成・見直し）
  • 給与計算のアウトソース → スタンダード月55,000円・創業3年以内45,000円（創業期向けの顧問）
  • 助成金の初回相談・申請支援 → 着手金0円・受給額の20％

PHASE 02 — 拡大期 仕組みを整える 従業員 10〜50名程度

こんな課題が多い

  • 就業規則の法改正対応が追いついていない
  • 残業・勤怠管理が曖昧で未払い残業代リスクがある
  • 育休・産休の規程が整備されていない
  • 採用・人件費が増加し管理が難しくなった

提案できること

  • 就業規則の全面見直し・法令対応 → 90,000円（就業規則の作成・見直し）
  • 勤怠管理ツール導入支援 → 5名まで100,000円（勤怠システム導入の手順）
  • 育休・産休規程の整備と手続き代行 → 育児介護休業規程 50,000円／1本（手続き代行）
  • キャリアアップ助成金等の申請代行 → キャリアアップ助成金

PHASE 03 — 組織強化期 仕組みを強くする 従業員 50名以上

こんな課題が多い

  • 人事評価・賃金体系が属人的で不透明
  • 管理職がハラスメント・労務管理の知識を持っていない
  • 賃金規程・退職金規程が無く、昇給・賞与の基準を説明できない
  • 法定研修・安全衛生体制の整備が遅れている

提案できること

  • 賃金規程・評価制度の構築サポート → 賃金規程 80,000円／1本（規程の作成）
  • 管理職向け労務管理・ハラスメント研修 → 30,000円／60分
  • 個別の労務相談・トラブルの初動整理 → 労務相談
  • 両立支援等・人材開発支援助成金の活用 → 両立支援等助成金／人材開発支援助成金

創業直後

創業直後にまず起きる手続き

法人を設立して社長ひとりでも、社会保険の新規適用届は設立から5日以内です（法人のひとり社長の健康保険｜加入は義務、報酬ゼロだと入れない）。初めて人を雇ったら、労働保険の保険関係成立届は雇入れから10日以内、雇用保険の適用事業所設置届も10日以内、雇用保険の資格取得届は翌月10日までです（入社手続きは社会保険5日以内・雇用保険は翌月10日まで）。ここで手続きを飛ばすと、後から遡って保険料を納める場面になります。当事務所は会社設立時の新規適用（3保険一式）を60,000円／事業所（5名まで・税抜）で、顧問契約なしでもお受けします（会社の労務手続き一覧と、社会保険・労働保険の手続き代行）。創業3年以内の顧問契約は月25,000円からです。
