01MISSION理念

複雑になった労務を、
シンプルで、使える形に。

企業が成長するにつれて、規程や手続き、勤怠・給与のルールは継ぎ接ぎになり、現場の負担が増えていきます。

私たちは複雑に絡み合った労務管理を一つずつほどき、本来の目的を残したまま、現場で続けられる仕組みへ整えます。

01

コストを意識した経営支援

助成金の活用と手続きの効率化を、費用対効果も見ながら提案します。

02

一つずつほどく実務

継ぎ接ぎになった規程と運用を整理し、本来の意図を残して整え直します。

03

長く使える仕組み化

法改正や組織の変化にも対応しやすい、現場で続けられる形を目指します。

04PRICING料金

業務範囲と料金がわかる、3つの選び方。

手続き中心、給与計算込み、31名以上・個別設計。主な業務範囲と料金を掲載しています。

顧問契約がなくても、お受けします。

目の前の1件だけを、固定料金でお受けします。料金はすべて税抜です。

  • 入社・退社の手続き初回限定 ¥5,000 / 1名2回目以降は ¥10,000 / 1名。書類がそろった翌営業日から3営業日以内に申請
  • 会社設立時の新規適用¥60,000 / 事業所（5名まで）労働保険・雇用保険・社会保険の3保険一式
  • 36協定の作成・届出¥20,000 / 事業所協定書の作成から労働基準監督署への届出まで
  • 就業規則の作成・改定¥90,000〜 / 事業所全面改定 ¥90,000、新規作成 ¥180,000。届出まで含みます
  • 助成金の申請代行成功報酬 受給額の20％着手金0円。受給できなければ報酬はいただきません
  • 労務相談（60分）初回無料2回目以降は ¥10,000 / 回。解雇・問題社員・ハラスメント対応など
単発のご依頼を相談する → 単発の料金をすべて見る →

05FAQよくある質問

ご相談の、その前に。

よくいただく疑問をまとめました。ここにない点も、初回のご相談で遠慮なくお尋ねください。

初回のご相談は無料でお受けしています。ご相談のみでも歓迎いたします。
従業員1名様からご対応しています。「これから人を雇う」「初めて社会保険に加入する」という段階も、よくあるご相談です。
プランの変更・見直しはいつでもご相談いただけます。契約期間や解約のお取り扱いは、ご契約前に書面でご説明し、ご納得いただいたうえで開始します。
業務内容によって異なります。オンライン相談や電子データでのやり取りに対応していますが、実務では情報を直接授受する場面も多いため、具体的な進め方はご相談時に貴社の業務形態や情報管理体制に合わせて調整します。ご来所や訪問が適する場合も含め、ご相談時に最適な方法をご案内します。
もちろん可能です。引き継ぎ手続きもサポートします。乗り換え時の不安や懸念点もヒアリングしたうえで対応します。
急なご相談も、まずはお電話（076-460-2562）またはお問い合わせフォームからご連絡ください。状況をうかがったうえで、できる限り速やかに対応します。
