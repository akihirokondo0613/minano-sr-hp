# みなの社労士 15秒CM 絵コンテ

- Composition: `MinanoLaborCm15`
- サイズ: 1280×720 / 30fps / 450フレーム
- 採用コンセプト: `paper-avalanche-freeze`
- 目的: HPトップから無料相談へ進んでもらう
- 固定方針: 全編16:9の安全域内、カメラ揺れなし、人物イラストを揺らさない

## ナレーション

1. 「手続き、給与計算、就業規則。」（速く、列挙）
2. 「その労務、積んでませんか？」（少し間を置き、問いかけ）
3. 「みなの社労士が、整理して支えます。」（温かく、確信を持って）
4. 「複雑な労務を、シンプルに。」（落ち着いて、ブランド着地）
5. 「まずは、ご相談ください。」（明るく、行動を促す）

## 時間割

### 0.0–3.0秒 / `paper-avalanche`

- 目的: 0.5秒以内に労務の困りごとを理解させる。
- 画: `17_admin_work_female.webp`を中央左へ固定。太い黒線で描いた巨大書類「入退社」「給与」「勤怠」「就業規則」が四方から迫る。
- 大テロップ: `手続き　給与　勤怠　規則`
- ブランド表示: 左上に小さく `みなの社労士`。
- 動き: 書類だけが`power3Out`で迫り、各カードが0.2秒ずつずれて着地する。人物は静止。
- 二次ビート: 1.8秒で書類がさらに一段積み上がる。
- 遷移: `cut`。2.9秒で全物体を完全停止。
- claimTags: `observed`

### 3.0–5.2秒 / `time-freeze-question`

- 目的: 問題を自分事にする。
- 画: 青の色面へ切り替え、停止した書類が画面端で凍る。中央に時計の秒針と大きな問い。
- 大テロップ: `その労務、積んでませんか？`
- 動き: 時計の秒針が一度だけ進み、`STOP`の丸印で停止。画面全体は揺らさない。
- 色: このシーンだけ`colorMode: inverted`。
- 遷移: `luma-wipe`。黒い一本線が右方向へ引かれて次の整列表になる。
- claimTags: `observed`

### 5.2–9.0秒 / `snap-organize-workflow`

- 目的: 社労士が何をしてくれるか視覚で示す。
- 画: `workflow-organizing.webp`を右側へ固定。左から書類カードが一本線へ吸い込まれ、`確認 → 期限 → 手続き`の3段へ整列。
- 大テロップ: `期限・手順を ひとつに`
- 補助表示: `みなの社労士が整理`
- 動き: カードを一枚ずつ`backOut`で差し込み、緑のチェックを押す。人物は静止。
- 二次ビート: 6.4秒、7.2秒、8.0秒に各カードが整列。
- 遷移: `whip-left`に相当する紙の横スワイプ。画面外クロップはせず、マスク内だけで処理。
- claimTags: `observed`

### 9.0–11.8秒 / `consultant-support-map`

- 目的: 単なる書類整理ではなく、実務と改善まで支援することを伝える。
- 画: `consult-documents.webp`を左側へ固定。右側に`手続き / 給与 / 就業規則 / 助成金 / 勤怠DX`の小さなタグが一本線でつながる。
- 大テロップ: `実務から、改善まで`
- 動き: 一本線を一筆書きし、タグが順に小さくポップする。人物は静止。
- 遷移: 黄色い円が拡大してCTA背景へ変わる`zoom-punch`。カメラ揺れなし。
- claimTags: `observed`

### 11.8–15.0秒 / `cta-card`

- 目的: 事務所名と相談行動を記憶させる。
- 画: 白地に青い丸の`み`印、`みなの社会保険労務士事務所`、中心メッセージ、青いCTAボタン。
- 大テロップ: `労務データを、会社の成長に変える。`
- CTA: `まずは無料相談`
- 動き: `み`印が軽くスタンプ着地し、CTAだけが一度ゆっくり呼吸する。2.5秒以上保持し、遷移アウトなし。
- claimTags: `observed`

## 表示安全域

- 外周: 48px以上
- 大テロップ: 上下左右80px以内
- 焼き込み字幕: 下端48px以上、CTAボタンと重ならない
- イラスト: `object-fit: contain`相当で全体を枠内に収める
- 重要要素は中央90%×84%以内に置く

## 表現上の制限

- 「必ず」「解決」「ミスゼロ」「最短」「丸投げ」などの保証表現を使わない。
- 数値実績を表示しない。
- 整列の速さは視覚的な比喩であり、処理時間の保証をナレーションしない。
- 参考CMの固有キャラクター、コピー、音源、構図を複製しない。
