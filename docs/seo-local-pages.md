# 地域SEO（富山＋業務語）の設計

目標は「富山＋業務＋料金/費用」の語で業務ページが検索に出ること。調査の正本は
`Desktop/01_🌐 Web・デザイン/ホームページ/_SEO調査/SEO現状調査と実行計画_20260824.html`。

## 決めごと

- **1ページ1語。** 同じ語を複数ページで狙わない（共食い）。割り当ては調査資料の図I。
  タイトルは「業務名＋費用/料金の語｜富山の社労士みなの」。地域を事務所名の括弧に埋めない。
- **料金の正本は `pricing.html` のまま動かさない。** 業務ページの料金抜粋は
  `scripts/sync-service-prices.mjs` が `#retainer-extra-fees` / `#spot-fees` / プランカードから
  抽出して `<!-- svc-fee:start/end -->` の間に生成する。手で書かない。
  meta description にも実額を書かない（料金改定でずれる場所を増やさない）。
- **業務ページに出すのはスポット価格**（検索者はまだ顧問先ではない）。顧問先50%は注記で示す。
- **助成金の率・計算例は抽出値から計算する。** 「受給できます」と断定しない。
  不支給時0円は着手金0円とセットで書く（他社相場との比較表は一次情報が無いので公開ページには載せない）。
- **富山固有の事実（住所・電話・管轄）は、公式サイトからの収集→独立の反証を通った値だけ使う。**
  記憶・台帳からの直接転記で公開ページに書かない。出典は公式ドメインに限る。
- **就業規則の新規作成・全面改定の固定額は未設定**（pricing.html に無い）。設定は本人判断。
  設定されるまで、ページには顧問プラン内の年次レビューと個別見積の事実だけを書く。
- 労務相談ページのタイトル変更（労基署調査対応の語）は、対応する本文が入る段2と同時に行う。

## 検証

- 生成器は `--check` を preflight に登録。マークアップ変更時は全幅の横はみ出し実測
  （320/390/768/1440）と、`run-layout-checks.cjs` を通す。
- 効果測定は Search Console の「富山」を含むクエリの表示回数（月次）。順位は表示が立ってから見る。
