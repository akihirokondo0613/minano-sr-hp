# 地域SEO（富山＋業務語）の設計

目標は「富山＋業務＋料金/費用」の語で業務ページが検索に出ること。調査の正本は
`Desktop/01_🌐 Web・デザイン/ホームページ/_SEO調査/SEO現状調査と実行計画_20260824.html`。

## 決めごと

- **1ページ1語。** 同じ語を複数ページで狙わない（共食い）。割り当ては調査資料の図I。
  タイトルは「業務名＋費用/料金の語｜富山の社労士みなの」。地域を事務所名の括弧に埋めない。
- **料金の正本は `pricing.html` のまま動かさない。** 業務ページの料金抜粋は
  `scripts/sync-service-prices.mjs` が `#retainer-extra-fees` / `#spot-fees` / プランカードから
  抽出して `<!-- svc-fee:start/end -->` の間に生成する。手で書かない。
  meta description にも実額を書かない（料金改定でずれる場所を増やさない）。
- **業務ページに出すのはスポット価格**（検索者はまだ顧問先ではない）。顧問先50%は注記で示す。
- **助成金の率・計算例は抽出値から計算する。** 「受給できます」と断定しない。
  不支給時0円は着手金0円とセットで書く（他社相場との比較表は一次情報が無いので公開ページには載せない）。
- **富山固有の事実（住所・電話・管轄）は、公式サイトからの収集→独立の反証を通った値だけ使う。**
  記憶・台帳からの直接転記で公開ページに書かない。出典は公式ドメインに限る。
- **就業規則の新規作成・全面改定の固定額は未設定**（pricing.html に無い）。設定は本人判断。
  設定されるまで、ページには顧問プラン内の年次レビューと個別見積の事実だけを書く。
- 労務相談ページのタイトル変更（労基署調査対応の語）は、対応する本文が入る段2と同時に行う。

## 富山の窓口一覧（uploads/toyama-madoguchi.html）

- 中身の正本は `data/toyama-madoguchi.json` だけ。`scripts/build-toyama-madoguchi.mjs` が生成する。
  骨組みは `uploads/service-romu-sodan.html` を型として写す（`build-joseikin-guides.mjs` と同じ方式）。
- **電話番号・住所は、公式サイトから収集したうえで、別のエージェントが出典を再取得して
  逐語で照合した値だけを使う。** 記憶・台帳からの転記で足さない。公開ページの誤りは信用に直結する。
- **注記は「記載がない」を「存在しない」に変えない。** 読者向けに書き直すときは、
  断定の強さを上げていないかを別のエージェントで照合する（今回4件の逸脱を捕まえた）。
- **出典側が難読化しているメールアドレスは、復元して載せない。** 相手の意図に反する。
- **同じ部署に番号が複数あるときは、番号ごとの担当まで出典で確かめる。そのうえで、
  出典どうしが食い違うなら片方に寄せない。** 富山労働局 雇用環境・均等室は
  076-432-2740と076-432-2728の2本がある。「担当一覧表」（PDF）では助成金は2728だが、
  富山労働局の業務改善助成金の案内ページは申請書類の確認先として2740を示している。
  どちらも同じ労働局の資料なので、両方を書いて用件を先に伝えてもらう形にする。
  一度これを2728だけに寄せて書き、あとで案内ページを見て直した。**片方だけ見て確定しない。**
- **官署の内部組織名は言い換えない。** 労働基準監督署の区分は「方面」であって「監督課」ではない。
  「監督課」は労働局労働基準部の課（076-432-2730）で、別物。
- **廃止された書類名を載せない。** 健康保険証は新規交付が終わっている。協会けんぽの窓口業務は
  「資格確認書・資格情報のお知らせ」で書く。
- 出典の表示はホスト名にする。URLをそのまま出すと、共通CSSの `p a { word-break: normal }` が効いて
  62文字級のURLが狭幅で折れず、器を押し広げる（320pxで実測）。
- 更新するときは出典URLを開き直し、`checkedAt` を進める。

## 業務ページの富山（uploads/service-*.html の `<!-- svc-toyama -->` 区間）

`scripts/sync-service-toyama.mjs` が生成する。設計は `data/service-toyama.json`。

- **「富山」を足すだけのページは評価されない。** 必要なのはその地域でしか書けない事実で、
  労務では「どの市町の会社が、どの窓口に出すのか」と「その県だけ違う数字」がそれにあたる。
- **窓口の住所・電話・管轄は、この生成器が持たない。** 正本は `data/toyama-madoguchi.json` の1つで、
  ここは `id` で指すだけ。市町村別の表は管轄の文字列を反転して組み立てるので、管轄が変われば表も変わる。
- **反転で取りこぼしたら止める。** `municipalityOrder` に無い管轄、どの窓口にも出てこない市町村が
  あれば例外にする。黙って行を落とすと、その市町の会社に「載っていない」という誤りを見せる。
- **窓口の数が系統ごとに違うことが、そのまま中身になる。** 富山は年金事務所4か所に対して
  ハローワークが7か所で、氷見市・滑川市・中新川郡・小矢部市は提出先の系統が分かれる。
- **数字は「いま有効な額」と「これから変わる額」を分けて書く。** 2026年8月時点の富山県最低賃金は
  答申（1,119円）が出ているが未発効で、守るべき下限は1,062円。値と注記を必ず対で出す。
  特定（産業別）最低賃金は地域別を下回るので、それだけを見て下限を判断させない。
- 数字には確認日と出典を必ず添える。年に一度は必ず変わる。
- **狭い幅では表を横スクロールにしない。** 560px以下は市町村ごとの塊に積み上げる（`data-label` を
  `::before` が読む）。3列目が画面外に切れると、そこに何かあること自体に気づけない。

## 検証

- 生成器は `--check` を preflight に登録。マークアップ変更時は全幅の横はみ出し実測
  （320/390/768/1440）と、`run-layout-checks.cjs` を通す。
- 効果測定は Search Console の「富山」を含むクエリの表示回数（月次）。順位は表示が立ってから見る。
