# トップのイラストと動き（2026-09-21）

## 採用する構成

本人指定により、トップの写真背景を相談風景のイラストへ置き換える。既存の太い輪郭・落ち着いた限定色を基準にし、事業主と相談担当者の2人を描く。代表者・事務所の実写は事務所案内に残す。

PCは文章とイラストを左右に配置する。スマホは文章→相談ボタン→イラスト→受付案内の順。本文、料金、法令、検索メタ、FAQ等の内容は維持する。受付案内はカードを重ねず、細い区切り線で整理する。

## 動きの設計

書類とカレンダーを独立したSVGにし、スクロール量に合わせて傾きが整い、書類が重なり、予定のチェックが描かれる。相談風景の人物や見出し・操作ボタンは動かさない。スクロールを強制停止したり、アニメーション完了まで本文を隠したりしない。

CSSのtransformと線の描画、1組の受動的スクロールリスナーを使用する。SPA再訪時は以前のリスナーを解除する。画面幅700px以下と動きを減らす設定では静止画として表示。新しいライブラリ・動画・外部フォントは導入しない。

02サービスと05FAQの見出し追従、および既存の一度きりのセクション表示を維持する。すべての章を新たな演出へ置き換えることはしない。

## 制作・公開手順

1. 既存イラストを作風資料として読み、相談風景を生成する。
2. 背景・人物・手足・文字混入を確認し、白背景の採用版を確定する。
3. 通常版1600×1200、軽量版960×720を保存。公開用は720/1200/1600pxのAVIFとWebPを生成する。
4. ページ固有CSSと動きを実装し、狭幅・中間幅・PC、動きを減らす設定、SPA往復を検証する。
5. preflight・PR CI合格後にマージ・デプロイし、本番で画像・動作・メタ情報を確認する。
6. 公開SHA、対象URL、GSC観察上の変更要因をCodex側のSEO変更台帳に保存する。

## 生成素材の来歴

生成：組み込みimage_gen。新規生成1回、背景修正1回。既存作風参照は sr-illustration-kit の reference-03-meeting-welcome.webp、reference-12-green-meeting.webp。参考サイト https://gaaboo.jp/ の画像・コードは転載していない。

初回プロンプト要旨：4:3の日本の社労士事務所用イラスト。左にくすんだ青の服の女性事業主、右に生成りの上着と淡緑のシャツの男性相談担当者。机上の資料を一緒に確認する。太い手描き風黒線、平面色、穏やかな表情、全身に余白。文字・ロゴ・吹き出しなし。

修正プロンプト要旨：人物・姿勢・机・資料を保ち、チェック柄を含む背景をすべて純白にし、余白を保つ。文字・小物は追加しない。
