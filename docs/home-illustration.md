# トップのイラストと動き（2026-09-21）

## 現行の方向

本人の「相談風景とかではなく、gaabooのように明るい雰囲気」という指定により、PR #313の相談場面を、働く人々が行き交う明るい街のイラストへ変更。緑を軸に黄色・コーラル・青を使用し、平面色と大きな形で活気を表す。登場人物は地域で働く人のイメージで、当事務所の人数や実在顧客を示すものではない。

大きな見出し・説明・相談ボタンを中央へ、その下へ横長の街を置く。スマホでは同じ作風の3人の構図へ切り替え、人物を小さくしすぎたり切り取ったりしない。料金・本文・営業条件・検索メタ・JSON-LDは変更しない。代表者・事務所の実写は事務所案内に維持する。

## 動きと読みやすさ

広い画面では花と鳥がスクロールに合わせて回転・移動し、街の絵も最大10px移動する。見出しと操作ボタンは動かさない。画面幅700px以下と動きを減らす設定では静止。再訪時は旧リスナーを解除し、受動的スクロールとrequestAnimationFrameで更新する。常時アニメーションや新しいライブラリ・動画・外部フォントは追加しない。既存02サービス・05FAQの見出し追従を維持する。

## 画像・軽量化

横長3:1は1200/2000px、スマホ4:3は720/1200pxのAVIFとWebP。pictureとmedia付きpreloadを一致させ、端末ごとに1枚だけ読む。画像領域の比率を先に確保する。旧相談画像はHTMLから参照しない。

## 生成素材の来歴

組み込みimage_genで横長版を新規生成し、細かすぎた描写を平面色へ修正。その採用版を参照しスマホ版を生成（新規1回・修正/再構成2回）。写真・gaabooの画像やコードの転載はない。https://gaaboo.jp/ は明るい配色、大きなイラスト、活気のある人物表現を参考にした。

初稿要旨：地域の店・飲食・ものづくり等で働く6人を描いた3:1の明るい街。緑・黄・コーラル・青、白背景、文字なし。
採用版への修正：大きな平面色と単純な顔、人物の年齢・体型に変化を付け、細かい描写を減らす。
スマホ版：同じ絵柄の店主・職人・花屋の3人を4:3に再構成。全身・余白を確保。

公開素材：assets/illustrations/hero-town-*。生成原本・完全なプロンプト・通常版・軽量版・検証画像は担当作業フォルダ outputs/トップを明るい街へ_20260921/ に保存。
