# 社内書式の根拠法令 逆引き表

このファイルは `python3 scripts/shoshiki/build_shoshiki.py` が生成する。手で直さない。
法改正があったら、その法令の行の書式を開き、本文（hints.py・forms_base.py・forms_extra.py）と解説（guide.law）を一次資料で確かめて直す。見直しの目安は毎年4月・10月（施行日が集中する4月1日・10月1日の後）。見直したら forms_base.py の `DATE` を更新する（現在 2026-10-04）。
通達・告示・ガイドラインだけを根拠にする書式は、法令の行から漏れるので、各書式の guide.law も読む。
