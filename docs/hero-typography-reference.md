# トップ見出しの文字サイズ参照

2026-10-04のユーザー依頼により、[富山アリーナ公式サイト](https://toyama-arena.co.jp/)の現行公開HTMLと[CSS](https://toyama-arena.co.jp/builds/web/index.scss.82531d58.css)を参照した。現在のファーストビューは画像バナーであるため、HTMLの文字サイズが確認できる「CONCEPT」「新時代アリーナ」の大小関係を参考にした。以下は通常の既定文字サイズ16pxで換算したCSSの指定値であり、参照サイトの実ブラウザ寸法の測定ではない。

| 参照要素 | PC | SP（740px以下） |
| --- | --- | --- |
| 日本語の主役見出し | 45〜60px、4.1667vw、weight 900、行間1.3 | 40px、weight 900、行間1.3 |
| 英語CONCEPT | 60〜90px、6.25vw、行間0.85 | 40〜56px、14.359vw、行間0.95 |
| 日本語の小見出し | 20〜25px | 17px |

みなのでは日本語の長さと人物との間隔に合わせ、サービス句をPC `clamp(56px,5.3vw,96px)`、SP `clamp(30px,8.2vw,42px)`、行間1.15・weight 900とした。1280pxで約68px、390pxで約32pxになる。緑の主張文はPC `clamp(32px,3.5vw,64px)`、SP `clamp(23px,6.8vw,32px)`、行間1.3とした。これは参照の強い大小差を適用する調整であり、参照サイトの値をそのまま移植したものではない。

既存の767px／768px境界を維持し、768〜1100pxではタイトル幅に合わせて主役42〜58pxへ調整する。文節の境界にあるwbrを有効にし、文節の途中で切らず折り返す。SPと狭いPCでは人物キャンバスの開始位置に余白を足し、大きくなったタイトルとの重なりを避ける。

ユーザーの補足画像にある最初の料金案内と目的別リンクも、同じトップページの文字階層として調整する。料金見出しは26〜40px、説明15〜18px、補足13px、詳細リンク16px。目的別リンクはPC16〜20px、SP14〜16pxにし、狭幅ではリンク内の間隔も調整する。料金の数値・適用条件・リンク先は既存内容を使う。

変更の合否は、Chromium／WebKitで実ページの文節矩形、文字サイズ、タイトルと着地後の人物との距離を測り、対象幅のCIスクリーンショットで確認する。
