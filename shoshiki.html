会社で使う
社内書式のひな形

入社から退職までに会社と従業員の間で使う申請書・届出・誓約書・通知書のひな形です。ブラウザで記入して印刷でき、会社名を入れると全書式に自動で入ります。登録は不要です。

!
ご利用にあたって書式は一般的な内容です。就業規則や労使協定と食い違うときは規程が優先します。入力した会社情報はブラウザ内にだけ保存され、当事務所には送信されません。使い方や就業規則との整合はお気軽にご相談ください。
社名

会社情報を入れる

最初に一度だけ入力してください。すべての書式の宛名・発信者欄に入ります。

いま設定されている会社名：【会社名】。入力した内容はこのブラウザの中にだけ保存され、当事務所には送信されません。各書式を開くと宛名・発信者欄に自動で入ります。別のPCで使うときは「書き出す」で保存したファイルを読み込んでください。

入社

内定から入社までに取り交わす書類

番号書式用途
D-01採用内定通知書採用内定を書面で通知する。内定は「始期付き・解約権留保付きの労働契約」と解されるため、取消事由をあらかじめ書いておく。記入する →
D-02入社承諾書内定者の入社意思を書面で確認する。記入する →
D-03選考結果のお知らせ不採用を通知する。記入する →
D-04入社誓約書入社時に基本的な遵守事項を誓約させる。記入する →
D-05健康状態告知書安全配慮義務（労契法5条）と適正配置のために、本人から健康状態を申告してもらう。記入する →
D-06緊急連絡先届緊急時に家族等へ連絡するための届。記入する →
D-07通勤経路届（通勤手当申請書）通勤手当の算定根拠と、通勤災害の「合理的な経路および方法」（労災法7条2項）の確認に使う。記入する →
D-08秘密保持誓約書入社時に秘密情報の範囲と取扱いを誓約させる。退職時にもう一度取る（D-28）。記入する →
D-09個人情報の取得及び利用に関する同意書個人情報と個人番号の利用目的を明示し、取得の同意を取る。記入する →
D-10身元保証書従業員が会社に損害を与えたときに保証人が賠償する約束。記入する →

D-29健康保険 資格喪失証明書退職者が国民健康保険に加入するとき、市区町村に出す資格喪失の証明を会社が発行する。記入する →
D-42解雇予告通知書解雇を30日以上前に予告する通知書。記入する →
D-43解雇理由証明書解雇された（または予告を受けた）従業員の請求に応じて、解雇の理由を証明する。記入する →
D-48継続雇用（再雇用）希望確認書定年を迎える従業員に継続雇用の希望を確認する。記入する →
D-49再雇用条件通知書定年後の再雇用の主な条件を本人に事前に知らせる。記入する →
D-51業務引継書退職・休職・異動のときに、担当業務を後任へ引き継いだ記録を残す。記入する →

注

この書式集について

書式は一般的な内容で、法令は2026年09月時点の理解に基づいて作っています。会社の就業規則・労使協定と食い違うときは規程が優先します。解雇・懲戒・労使協定など、書式だけでは判断できない場面は、使う前に専門家にご確認ください。

自社内での利用と改変は自由です。第三者への再配布・販売はご遠慮ください。作成・提供：みなの社会保険労務士事務所（富山市）。

書式の使い方や、就業規則との整合はご相談ください

解雇・懲戒・労使協定など、書式だけでは判断できない場面は、状況を伺ってから進め方をお伝えします。
